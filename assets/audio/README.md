Playback starts only after a visitor clicks the small music button. The player requires an internet connection while streaming. To self-host the file instead, download it from the official page, place the unmodified MP3 here as `sleep.mp3`, then change `music.src` in `js/content.js` to `assets/audio/sleep.mp3`.
